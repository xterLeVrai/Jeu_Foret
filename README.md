# Gare au Renard ! 🦊🌲

Jeu d'arcade 2D rétro et coloré en HTML5 Canvas et JavaScript pur.

Attrapez les animaux de la forêt et ramenez-les vite dans le poulailler avant que le renard ne vienne les dérober !

---

## 🎮 Comment Jouer

1. Double-cliquez sur `forest_game/index.html` (ou ouvrez-le dans votre navigateur préféré).
2. Entrez votre nom ou pseudo.
3. Appuyez sur **Entrée** ou cliquez sur **Commencer l'aventure 🌲**.

---

## 🕹️ Commandes

| Action | Clavier (AZERTY / QWERTY) | Flèches | Manette USB |
| :--- | :--- | :--- | :--- |
| **Se déplacer** | **Z Q S D** ou **W A S D** | **⬆️ ⬇️ ⬅️ ➡️** | Stick analogique gauche |
| **Pause / Reprendre** | Touche **P** ou **Échap** | - | - |
| **Valider le nom** | Touche **Entrée** | - | Bouton A / Croix |
| **Rejouer** | Bouton écran | - | Bouton A / Croix |

---

## 🎯 Objectif & Points

* **Objectif** : Atteindre **30 points** le plus vite possible pour inscrire son record au Panthéon des scores !
* 🐇 **Lapin** : +1 point
* 🐔 **Poule** : +2 points (avec caquètement sonore !)
* 🌟 **Poule d'Or** : +10 points (très rapide et éphémère !)
* ⚡ **Éclair jaune** : Bonus de super vitesse temporaire
* 🦊 **Renard** : Fonce sur le poulailler pour vous voler 2 points ! Heureusement, votre fidèle chien veille et aboie pour le faire fuir quand il approche.

---

## 🌐 Déploiement en ligne gratuit (GitHub Pages)

Vous pouvez héberger le jeu gratuitement et y jouer directement en ligne depuis votre navigateur :
1. Dans votre dépôt GitHub, allez dans l'onglet **Settings** > **Pages**.
2. Sous **Build and deployment** > **Branch**, sélectionnez la branche `main` et le dossier `/root` (ou `/forest_game`).
3. Cliquez sur **Save**. Votre jeu sera accessible en quelques instants à l'adresse : `https://<votre-pseudo>.github.io/<nom-du-repo>/forest_game/` !
